01

The peripheral

A register map any SoC bus master can talk to, sitting on top of a UART datapath built from first principles.

APB REGISTER MAP4 registers
OffsetRegisterAccessFunction
0x00TXDATAWByte to transmit
0x04RXDATARLast received byte
0x08STATUSRTX busy / RX valid flags
0x0CBAUDDIVR/WBaud rate divider

The datapath runs on a 16× oversampled baud generator driving separate FSM-based TX and RX shift registers. The RX path carries a 2-flop input synchronizer on the incoming serial line — the standard defense against metastability on an asynchronous external signal, and a detail it's easy to skip until it bites you on real hardware.

Verification

03

On real silicon

Simulation passing is necessary, not sufficient. The design was synthesized, implemented, and programmed onto a real Nexys A7 (Artix-7 XC7A100T) via a board-level wrapper — switches drive TXDATA, LEDs reflect STATUS, closing the loop from RTL to a physical part.
