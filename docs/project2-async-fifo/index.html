Architecture

The Cummings SNUG 2002 dual-clock design — the reference architecture nearly every real async FIFO in industry traces back to.

  • ▸Gray-code pointer synchronization — binary pointers change multiple bits per increment, which is unsafe to sample across a clock boundary; Gray code guarantees only one bit ever changes
  • ▸2-flop synchronizers on every signal crossing between the write-clock and read-clock domains, the standard metastability guard
  • ▸Independent 100 MHz write-side and 66 MHz read-side clock domains, genuinely asynchronous to each other

Formal proof

The no-overflow safety property proven via SymbiYosys/Boolector, bounded model checking to depth 20 — the property holds across every reachable state the solver can explore that deep, not just the states a directed testbench happened to hit.

Alongside the formal proof, a self-checking testbench exercised both domains independently: 121 writes, 121 reads, 0 mismatches across the full 100 MHz / 66 MHz clock split.

03

The bug that mattered more than the proof

Caught and fixed

The first proof attempt passed — and was wrong. Unresolved hierarchical signal references meant the solver was checking a property that was structurally disconnected from the real design: a vacuous proof, one that reports success because it's checking nothing.

The lesson

A vacuous proof is worse than no proof — it actively creates false confidence. Fixing the hierarchical reference and re-running produced a proof that actually constrains the design. This exact lesson was carried forward and applied when auditing Project 4's CPU formal proofs, where two more vacuous proofs were caught before being trusted.
