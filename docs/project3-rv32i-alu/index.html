The false counterexample

Caught and diagnosed

The SRA property's formal proof reported a counterexample — but the failing input, when hand-traced, didn't actually violate the specification. The counterexample was false, not a real design bug.

Root cause

Traced to a Boolector SMT-translation quirk on variable-shift arithmetic right shift — the solver's bit-vector encoding of a variable shift amount interacted with the sign-extension logic in a way that produced a spurious failing trace. Diagnosing this required distinguishing "the solver found a real bug" from "the solver's translation of the problem has a gap," which is a genuinely different skill from writing the RTL in the first place.
